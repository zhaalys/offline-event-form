# offline-event-form

3D Comic Forest — guestbook interaktif dengan form nama & pesan.

- Nama + pesan tampil sebagai karakter komik di hutan 3D (Three.js)
- Data dikirim ke Google Sheets via Google Apps Script untuk disimpan
- Drag untuk melihat, scroll untuk zoom

## Cara pakai

1. Buka `index.html` di browser.
2. Isi nama dan pesan, klik **Send Message**.
3. Data masuk sebagai baris baru di Google Sheet (lewat Apps Script).

## Struktur

- `index.html` — halaman utama
- `style.css` — styling
- `script.js` — Three.js 3D scene + form handling
